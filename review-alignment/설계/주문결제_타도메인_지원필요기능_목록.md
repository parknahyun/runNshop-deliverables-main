# Order·Payment 도메인이 타 도메인에 요구하는 지원 기능 목록

**작성일**: 2026-11-04
**대상**: Order·Payment 도메인 (S2-구조설계·S3-상세설계 전체)
**용도**: Order·Payment가 다른 도메인에 의존하는 기능을 도메인별로 모아, 담당자가 타 도메인 지원 범위를 검토·확정할 때 쓰는 목록이다. **협의내용** 열은 각 항목을 해당 도메인 담당자와 논의할 때 구체적으로 물어야 할 질문·결정 포인트를 적은 것이며, 아직 합의된 결론이 아니라 "이것부터 맞춰야 한다"는 의제다.
