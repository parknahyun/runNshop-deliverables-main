## Catalog 화면 ↔ API 매핑 (2026-09-28 보강)

> DN-화면레이아웃/catalog-admin.md에서 설계된 7개 화면을 메뉴 경로에 연결하고, 각 화면이
> 실제로 호출하는 API(DL-인터페이스명세/catalog.md)를 요약한다. "메뉴 → 화면 → API"를 한
> 표에서 추적할 수 있게 하는 목적이며, API 상세 스펙은 DL을, 화면 레이아웃 상세는 DN을 참조.

| 메뉴 경로 | 화면 (SCR-ID) | 주요 호출 API (DL §) |
|---|---|---|
| 상품관리 › 직매입 등록 | 직매입 상품 등록 (SCR-A-C01) | §3 상품 등록(직매입) |
| 상품관리 › 상품심사 | 심사 목록 (SCR-A-C02) | §27 상품 목록(status 필터) |
| 상품관리 › 상품목록 › (행 클릭) | 상품 상세 (SCR-A-C04) | §29 상세조회, §4~6 심사처리, §8~11 기본정보/이미지/옵션/단종, §16·§16-1 가격 |
| 상품관리 › 상품목록 | 상품 목록 (SCR-A-C03) | §27 상품 목록 |
| 상품관리 › 노출우선순위 | 노출 우선순위 관리 (SCR-A-C06) | §27 목록조회, §21 수동순위설정 |
| 상품관리 › 분류체계관리 | 분류체계 관리 (SCR-A-C05, 2026-11-09 전시 카테고리 탭 제거) | §12 생성/수정/삭제, §12-1 목록조회(표준·브랜드) |
| 전시관리 › 페이지 | 전시 페이지 목록·편집 (SCR-A-C07·C08) | §30 목록, §30-1 단건조회, §22 생성/게시/종료, **§31 홈으로 설정(2026-09-28 추가)** |
| 전시관리 › 카테고리 | 전시카테고리 관리 (SCR-A-C10, 2026-11-09 신설) | §12 생성/수정/삭제, §12-1 목록조회(전시) |
| 전시관리 › 상품순서 | 전시카테고리 상품순서 관리 (SCR-A-C09, 2026-11-09 신설) | §39 목록조회·순서저장 |
| 전시관리 › GNB메뉴 | GNB 메뉴 관리 (SCR-A-C11, 2026-11-09 신설) | §42 등록/수정/삭제/순서저장, §42-1 목록조회 |

> **구 메뉴구조와의 차이**: 1차 파트 작성 당시 "카테고리(표준)"·"카테고리(전시)"·"브랜드"·
> "섹션"·"템플릿" 5개 2depth로 나눠뒀던 placeholder를 DN 설계 결과에 맞춰 통합·조정했다.
> - 카테고리(표준)·카테고리(전시)·브랜드 3개 → **"분류체계관리" 1개**로 통합 (DN SCR-A-C05가
>   InnerTabs 하나로 3개를 모두 처리하도록 설계됨)
> - "섹션" 별도 메뉴 → **삭제** (DN SCR-A-C08 전시 페이지 편집 화면 내부에서 섹션 구성을
>   함께 처리, 별도 화면/메뉴가 아님)
> - "템플릿" 별도 메뉴 → **DN에 대응 화면 없음** (Human Review — 템플릿 관리 화면이
>   필요한지, 아니면 섹션 편집 시 레이아웃을 직접 구성하는 방식으로 대체되는지 미확정)
> - "직매입 등록"·"노출우선순위" 2개 메뉴 → **신규 추가** (기존 placeholder에 없던 화면,
>   DC-상위유스케이스/DK-세부유스케이스 재검토 과정에서 발견되어 DN에 반영됨)
> - "전시관리 › 페이지" → **"홈으로 설정" 액션 추가**(2026-09-28, 별도 메뉴 신설 없음) —
>   mobile "홈" 메뉴(아래 참조)에 노출할 페이지를 이 화면에서 지정. 상세는
>   `DBA-도메인정책서/catalog.md` §6.4 참조
> - "전시관리 › 카테고리"·"전시관리 › 상품순서" → **신규 추가(2026-11-09)** — 전시 카테고리가
>   고객이 보는 카테고리 메뉴(mobile `/category`)의 데이터 원천으로 확정되면서, 기존
>   "상품관리 › 분류체계관리"의 전시 카테고리 탭을 분리하고, "상품관리 › 전시카테고리
>   상품순서"도 함께 이쪽으로 옮겼다(DBA §2.5.1·§2.5.3)
> - "전시관리 › GNB메뉴" → **신규 추가(2026-11-09)** — 고객 홈 화면 Header 하단 퀵메뉴 바에
>   노출할 메뉴(랭킹·기획전·테마관 등)를 관리자가 직접 구성하는 화면. 전시 페이지 뷰어
>   (비홈) 화면 미설계 논의에서 진입 경로 보완 필요성으로 도출(DBA §2.14)
