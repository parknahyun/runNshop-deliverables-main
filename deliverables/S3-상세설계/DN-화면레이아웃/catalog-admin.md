### 와이어프레임

```
┌──────────────────────────────────────────────────────────────────────┐
│ 직매입 상품 등록                                                     │
├──────────────────────────────────────────────────────────────────────┤

│                                                                      │
│                                        [취소]  [등록 완료]           │
```

### 화면 구성

| 영역 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| 등록 폼 | — (FE 입력) | 상품명·카테고리·브랜드·정가·판매가·공급가·출시일·설명 입력 필드 |
| 경고 안내 | — | 직매입 등록은 심사 게이트 없이 즉시 ON_SALE 전환됨을 고지 |

### 기능 (Function)

| 기능명 | 트리거 | 동작 | 검증/제약사항 |
|---|---|---|---|
| 직매입 등록 | [등록 완료] 클릭 | `POST /api/admin/v1/products` (isDirectSourced=true) → 상태 DRAFT→ON_SALE 즉시 전환 | 필수 필드 누락 시 REQUIRED_FIELD_MISSING(400), 가격 구조 위반 시 PRICE_RULE_VIOLATION(422) |

### 화면 전환

| 트리거 | 이동 화면 (SCR-ID) |
|---|---|
| [등록 완료] 성공 | SCR-A-C04 (상품 상세, 방금 등록한 상품으로 이동) |
| [취소] 클릭 | SCR-A-C03 (상품 목록) |

### 유효성 검증

> [[DJ-GWT수용기준/catalog\|GWT §1 상품등록·심사(직매입) Bolt]], AC-CAT-001~002 · 에러코드는 DL §3 참조

|---|---|
| 등록 처리 중 | [등록 완료] 버튼 비활성화 + 스피너 |

### 화면 구성

| 영역 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| FilterBar | — (FE 상태) | 상태 Select(REVIEW_REQUESTED/UNDER_REVIEW 등), 카테고리, 키워드 |
| SummaryBar | GET /api/admin/v1/products?status=... → 집계 | 심사요청·심사중·반려(30일내)·에스컬레이션 건수 카드 |

> **판매가 컬럼 주의**: `cat_product`에 저장된 필드가 아니다. `priceSale`은 API 응답 조립 시
> `cat_product_price_schedule`에서 조회 시점(now) 기준 유효 행을 join하여 채운 값이다
> (DBA §4.1-1, DL §27). 이 화면은 조회 전용이라 영향 없지만, 수정은 §4 가격 탭에서만
> 가능하다(가격 탭은 별도 `price-schedule` API로 기간별 행을 추가하는 구조).

### 화면 구성

| 영역 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| 헤더 | GET /api/admin/v1/products/{id} | 상품명, 상태 뱃지, 판매자명+등록경로 |
| 기본정보 탭 | GET /api/admin/v1/products/{id} | name·요약(summary)·categoryId·brandId·releaseDate·isDirectSourced·description·태그(tags)·전시여부(isExposed)·검색노출제외(isSearchExcluded) — 요약·태그는 2026-11-09 소급 반영(DBA §1.3.1·§1.3.3·§1.3.4), 전시여부·검색노출제외는 2026-11-09 신설(DBA §2.16, 전시 탭 폐지로 통합) |
| 심사 탭 | GET /api/admin/v1/products/{id} (rejectReason·rejectCount 포함) | 현재 상태, 심사 착수/승인/반려 액션 |
