## 8-2. mobile — 반품/교환 신청 (ClaimRequestPage)

> **진입**: 주문상세([SCR-M-007_order-detail.md](../order/SCR-M-007_order-detail.md)) 또는 주문/배송 조회([SCR-M-006_my-orders.md](../order/SCR-M-006_my-orders.md))에서 [반품/교환] 버튼 클릭 시 이동.
> 복수 아이템 선택은 주문상세에서만 가능 ([SCR-M-006_my-orders.md의 "정책 미결 사항"](../order/SCR-M-006_my-orders.md#정책-미결-사항) 방안1 참조).
> **반품/교환은 판매자(ord_order) 단위로만 진행** — 동일 판매자 주문 내 아이템만 선택 가능.

> **구현 현황 (2026-10-29)**: 이 화면(SCR-M-008)은 설계안이며 프로토타입 미구현이다 — FE에 라우트가 없고(`app/my/orders/`·`app/my/claims/` 하위) BE에도 `POST /api/mobile/v1/my/orders/{orderId}/claims`(API-013)가 없다. 사진 필수(REQ-ORD-058)·교환 옵션·귀책 안내 등 아래 내용은 구현 전 설계 기준이다. 주문 상세의 [반품/교환] 버튼은 현재 alert만 띄운다.

### 화면 구성

| 영역 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| Header | — | "← 반품/교환 신청" |
| 신청 유형 | — (FE 상태) | 반품/교환 라디오 선택 |
| 신청 상품 선택 | GET /api/mobile/v1/my/orders/{orderId} (API-015) → `items[]` | 클레임 가능 아이템 목록 (클레임 가능 수량 > 0인 아이템만 표시), 체크박스 + 수량 선택. **클레임 가능 수량 = 주문수량 − 접수된 클레임 수량이며, 반려·결제만료 건은 재신청 가능하므로 차감 대상에서 제외** |
| 교환 옵션 선택 | GET /api/v1/products/{productId}/skus (재고 있는 옵션만) *[확인 필요: 이 경로는 DL(order·catalog)에 정의가 없다. 현행 상품 조회 API는 DL catalog.md의 `GET /api/mobile/v1/products/{productId}`이며 SKU 목록 제공 여부는 확인 필요 — 경로는 바꾸지 않았다]* | **신청 유형이 "교환"일 때만 노출.** 선택한 아이템별로 변경할 색상/사이즈 옵션 드롭다운 표시. **선택된 옵션의 skuId가 CTA 요청의 `exchangeSkuId`로 전달됨** — 미선택 시 [신청하기] 비활성화 |
| 사유 선택 | — (정적 목록) | 단순변심, 사이즈 불일치, 상품불량, 오배송, 기타 |
| 상세 사유 | — (FE 입력) | 텍스트 입력 (선택) |
| 귀책 안내 | — | 고객 귀책 사유 선택 시 배송비 발생 안내 문구 노출 |
| 사진 첨부 | — (FE 업로드) | 최대 3장. **판매자(VENDOR) 귀책 사유(상품불량/파손, 오배송) 선택 시 1장 이상 필수** — 0장이면 [신청하기] 비활성화 + "상품 상태를 확인할 수 있는 사진을 1장 이상 첨부해주세요" 안내 (REQ-ORD-058). 고객 귀책 사유는 선택 |
| 회수지 | GET /api/mobile/v1/my/orders/{orderId} (API-015) → `shipping` (기본값) | 주문 배송지를 기본 표시. [변경] 클릭 시 배송지 선택 팝업 ([SCR-M-002_order-sheet.md](../order/SCR-M-002_order-sheet.md)의 배송지 팝업과 동일, 설계안) |
| CTA | POST /api/mobile/v1/my/orders/{orderId}/claims (API-013, 프로토타입 미구현) | [신청하기] → 클레임 접수. 교환 신청 시 아이템별 `exchangeSkuId`(교환 옵션 선택값) 포함 |

### 유효성 검증

> [[DJ-GWT수용기준/order|GWT §8 클레임(반품·교환) Bolt]] · 사진 첨부 필수 조건(REQ-ORD-058)은 DL CLAIM_PHOTO_REQUIRED 참조

> **신청 기한 (2026-10-29 확정)**: 단순변심 반품·교환은 **배송완료 후 10일** 이내에 신청한다(정책서 order-claim.md 7.2.2·7.2.4, DD REQ-ORD-030). 기한이 지나면 주문 상세에서 [반품/교환]을 숨기고, 직접 접근 시 "기한이 초과되었습니다"를 안내한다. 하자·오배송(판매자 귀책)은 배송완료 후 3개월 또는 안 날부터 30일 이내이며, 기한 안이라도 **구매확정 후에는 모바일에서 신청할 수 없고 고객센터로 요청하면 어드민이 접수**한다(REQ-ORD-081, 정책서 7.2.1, 2026-10-29 확정). 따라서 구매확정 후 주문 상세에서는 [반품/교환] 버튼을 숨기고 "구매확정 후에는 고객센터로 문의해주세요"를 안내한다. 기한 후 하자 접수는 운영자 승인(7.2.3)이다. 자동 구매확정은 배송완료 후 11일이라 단순변심 접수 가능 기간(10일) 전체가 구매확정 전이다.
