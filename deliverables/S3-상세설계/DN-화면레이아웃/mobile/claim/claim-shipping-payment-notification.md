## 8-5. mobile — 클레임 배송비 결제 완료 알림 (ClaimShippingPaymentNotification)

> 클레임 수거/반송 배송비 결제 완료 시 발송되는 **알림톡 + 이메일** 레이아웃.

### 메타블록

| 항목 | 내용 |
|---|---|
| 화면 ID | 없음 (외부 채널) |
| 앱 | mobile (딥링크 유입) |
| 접근 권한 | 해당 회원 전용 딥링크 |
| 관련 세부UC | 해당 없음 (알림 발송은 시퀀스(DM) 컨슈머 로직에서 트리거) |
| 호출 API | 해당 없음 |

### 화면 전환

| 트리거 | 이동 화면 (SCR-ID) | 발송 시점 |
|---|---|---|
| 딥링크 클릭 (수거 배송비 결제 알림) | SCR-M-010 (클레임 목록) `/my/claims` | 배송비 결제 완료 즉시 |
| 딥링크 클릭 (반송 배송비 결제 알림) | SCR-M-010 (클레임 목록) `/my/claims` | 반송 배송비 결제 완료 즉시 |

### 수거 vs 반송 메시지 차이

| 구분 | 알림톡 메시지 | 이메일 다음 단계 안내 |
|---|---|---|
| 수거 배송비 결제 | "수거가 진행됩니다. 택배 기사 방문 예정 (1~2일 내)" | 수거 → 품질점검 → 환불 |
| 반송 배송비 결제 | "상품이 반송됩니다. 1~3일 내 수령 예정" | 반송 배송 후 배송완료 안내 예정 |
