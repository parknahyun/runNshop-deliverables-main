## 8-4. mobile — 클레임 접수 완료 알림 (ClaimReceivedNotification)

> 클레임 접수 완료 시 발송되는 **알림톡 + 이메일** 레이아웃.

### 메타블록

| 항목 | 내용 |
|---|---|
| 화면 ID | 없음 (외부 채널) |
| 앱 | mobile (딥링크 유입) |
| 접근 권한 | 해당 회원 전용 딥링크 |
| 관련 세부UC | 해당 없음 (알림 발송은 시퀀스(DM) 컨슈머 로직에서 트리거) |
| 호출 API | 해당 없음 |

### 와이어프레임 — 카카오 알림톡

```

├─────────────────────────────────────┤
│                                     │

│ 완료되었습니다.                      │
│                                     │
│ ■ 클레임번호: CLM-20260628-001     │
│ ■ 유형: 반품                        │
│ ■ 상품: 나이키 페가수스 41          │
│ ■ 접수일: 2026.06.28               │
│                                     │
│ 처리까지 1~2일 소요되며,            │

│ └─────────────────────────────────┘ │
│                                     │
└─────────────────────────────────────┘
```

### 화면 전환

| 트리거 | 이동 화면 (SCR-ID) | 발송 시점 |
|---|---|---|
| 딥링크 클릭 (카카오톡) | SCR-M-010 (클레임 목록) `/my/claims` | 클레임 접수 즉시 |
| 딥링크 클릭 (이메일) | SCR-M-010 (클레임 목록) `/my/claims` | 클레임 접수 즉시 |

### 고객 귀책 vs 판매자 귀책 차이

| 구분 | 알림톡 | 이메일 수거 안내 |
|---|---|---|
| 고객 귀책 | "배송비 결제 후 수거가 진행됩니다" 추가 | 수거 배송비 + 결제 기한 안내 |
| 판매자 귀책 | "수거가 자동으로 진행됩니다" | "수거 배송비: 무료 (판매자 부담)" |
