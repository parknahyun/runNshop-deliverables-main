> **구현 현황 (2026-10-29)**: 클레임 목록은 `ClaimController.kt`의 Mock GET 조회만 구현돼 있다(Service/DB 미연동). 와이어프레임의 "⚠️ 배송비 결제 필요 (12시간 남음)" 강조는 `ClaimListItem.tsx`에 없고(프로토타입 미구현), 금액은 "아이템 결제금액"이 아니라 `refundAmount`를 표시한다. 상태 요약 카운트·강조 표시는 설계안이다.

### 화면 구성

| 영역 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| Header + 뒤로가기 | — | "← 취소/반품/교환 내역" 타이틀 |
| 상태 요약 카운트 | GET /api/mobile/v1/my/claims (API-016) → 집계 | 접수·처리중·완료·반려 건수 |
| 클레임 카드 목록 (ClaimListItem) | GET /api/mobile/v1/my/claims (API-016) → `claims[]` | 유형뱃지(취소/반품/교환), 클레임번호, 상태뱃지, 상품이미지, 상품명*, 옵션*, 사유, 환불금액(설계안: 상품주문금액 기준 / 현행: `refundAmount`), 접수일. "배송비 결제 필요(N시간 남음)" 강조는 설계안(프로토타입 미구현) |
| 카드 클릭 | — | 클레임 상세 화면(/my/claims/{claimId})으로 이동 |
| BottomNav | — | 홈/기획전/검색/MY |

> \* 상품명·옵션명은 상품(Catalog)의 현재 속성이 아닌 **주문(ord_order_item)의 스냅샷 속성**을 사용한다. 클레임 상세([SCR-M-011_claim-detail.md](SCR-M-011_claim-detail.md))도 동일.
