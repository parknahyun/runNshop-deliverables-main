## 8-6. mobile — 클레임 처리 완료 알림 (ClaimCompletedNotification)

> 클레임 처리 완료(환불 포함) 시 발송되는 **알림톡 + 이메일** 레이아웃.

### 메타블록

| 항목 | 내용 |
|---|---|
| 화면 ID | 없음 (외부 채널) |
| 앱 | mobile (딥링크 유입) |
| 접근 권한 | 해당 회원 전용 딥링크 |
| 관련 세부UC | 해당 없음 (알림 발송은 시퀀스(DM) 컨슈머 로직에서 트리거) |
| 호출 API | 해당 없음 |

### 화면 전환

| 트리거 | 이동 화면 (SCR-ID) | 발송 시점 |
|---|---|---|
| 딥링크 클릭 (클레임 완료 — 반품) | SCR-M-010 (클레임 목록) `/my/claims` | 품질점검 합격 + 환불 요청 시점 |
| 딥링크 클릭 (교환상품 선출고 발송) | SCR-M-010 (클레임 목록) `/my/claims` | 선출고 시점 (PICKUP 진입) |
| 딥링크 클릭 (클레임 완료 — 교환) | SCR-M-010 (클레임 목록) `/my/claims` | 품질점검 합격(택 유지 확인) 시점 |

### 유형별 메시지 차이

> **환불 산식 (2026-10-29 확정)**: 수거 배송비(6,000원)는 고객이 수거 전에 별도 결제했으므로 환불금액에서 차감하지 않는다. 환불금액 = 상품주문금액 151,028원.

| 유형 | 알림톡 핵심 메시지 | 이메일 환불 내역 |
|---|---|---|
| 반품 | "반품 처리가 완료되었습니다" + 환불금액·환불수단·환불예정일 | 아이템금액 − 배송비 = 환불금액 상세 |
| 교환(선출고 발송, EXCHANGE_SHIPPED) | "교환 상품이 발송되었습니다." + 교환 운송장번호 (PICKUP 진입 즉시 발송 — 품질점검 이전) | 환불 내역 대신 "교환 상품 발송 정보" 표시 |
| 교환(클레임 완료, CLAIM_COMPLETED) | "교환 처리가 완료되었습니다." (원상품 회수·품질점검 완료 안내, 재발송 문구 없음 — 이미 발송됨) | 발송 정보는 위 알림에서 안내 완료 |
| 취소 | "주문 취소가 완료되었습니다" + 환불금액·환불수단·환불예정일 | 전액 환불 (배송비 차감 없음) |
