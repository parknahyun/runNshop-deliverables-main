## 6. mobile — 주문 확인 이메일 (OrderConfirmationEmail)

> 앱 내 화면이 아닌 **이메일로 발송되는 HTML 메일** 레이아웃 정의.

### 메타블록

| 항목 | 내용 |
|---|---|
| 화면 ID | 없음 (외부 채널 — DQ 프로그램목록에 SCR 미등록) |
| 앱 | mobile (딥링크 유입) |
| 접근 권한 | 해당 회원 전용 딥링크 |
| 관련 세부UC | 해당 없음 (알림 발송은 시퀀스(DM) 컨슈머 로직에서 트리거) |
| 호출 API | 해당 없음 |

### 화면 구성

| 영역 | 데이터 소스 | 표시 내용 |
|---|---|---|
| 로고 + 인사말 | Member 도메인 → `name` (마스킹) | "홍*동님, 주문이 완료되었습니다." |
| 주문 정보 | Order 이벤트 payload | 주문번호(platformOrderNo), 주문일시, 결제금액, 결제수단(마스킹) |
| 주문 상품 목록 | Order 이벤트 payload → `items[]` | 상품이미지 URL, 상품명, 옵션, 수량, 금액 |
| 배송지 정보 | Order 이벤트 payload → `shipping` | 수령인(마스킹), 연락처(마스킹), 주소 |
| 결제 내역 | Order 이벤트 payload → `price_summary` | 상품금액, 할인, 배송비, 주문금액, 포인트, 결제금액 |
| CTA 버튼 | — | "주문 상세 보기" → 딥링크 `/my/orders` |
| 안내사항 | — (정적 텍스트) | 배송 소요, 취소 정책, 고객센터 |
| 푸터 | — (정적) | 회사 정보, 수신거부 링크 |

> 주문번호 표기(2026-10-29 정리): 와이어프레임 예시는 현행 P/V 체계로 갱신돼 있다 — 화면·알림이 표시하는 주문번호는 `platformOrderNo`("P"+yyMMdd+"-"+5자리+"-00")이고, vendor 주문번호(`Order.orderNo`, "V"+yyMMdd+"-"+5자리+"-NN")는 partner 채널 전용이다.
